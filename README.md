# 🍳 Asistente Culinario Visual con Chef Interactivo
> **Documentación de Arquitectura de la Información (AI) del Prototipo / Mockup**

Este repositorio contiene la propuesta y el prototipo interactivo para el **Asistente Culinario Visual**, una plataforma de escritorio (Tauri + Svelte) diseñada para guiar a los usuarios en la cocina mediante reconocimiento de ingredientes por visión artificial y un avatar interactivo en tiempo real.

Para este avance académico, el mockup fue diseñado e implementado contemplando de manera explícita **Los Cuatro Sistemas de la Arquitectura de la Información**: **Organización**, **Etiquetado**, **Navegación** y **Búsqueda**.
